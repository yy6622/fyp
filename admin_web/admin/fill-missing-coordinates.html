Fill Missing Coordinates

One-off tool: looks up real lat/lng (via Geoapify/OpenStreetMap, same API already used by fix-missing-addresses.html) for every attraction, restaurant and hotel that doesn't have one yet, and saves it (lat/lng only — nothing else is touched). Without this, Optimise's geographic area-grouping has nothing to work with for these records. Free Geoapify tier is 3,000 lookups/day — if this run stops partway because of that, reload tomorrow to pick up the rest. Delete this page once you're done with it.

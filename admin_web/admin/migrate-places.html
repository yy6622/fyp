Catalog places migration

One-off tool: retires the old, unused catalog_places collection and renames the live places collection to catalog_places.

What this does

catalog_places is old, orphaned data from an earlier version of the app — nothing in the current app reads it any more. places is the real, actively-used pre-scraped attraction dataset the Explore tab reads from today. Running this will, in order: (1) download a backup of whatever is currently in catalog_places, (2) delete it, (3) copy every document from places into catalog_places (same document ids), then (4) delete the now-copied documents from places. This cannot be undone except by restoring from the downloaded backup file.

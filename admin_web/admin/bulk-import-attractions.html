Bulk Import Attractions

One-off tool: finds up to 15 real attractions (museums, zoos, parks, heritage sites, viewpoints — real OSM/Geoapify data, never invented) near every city that already has restaurants, and adds the ones not already in the catalogue. Safe to stop and re-run later — cities that already have enough attractions are skipped automatically, so this can continue across several days if the free API quota runs out.
